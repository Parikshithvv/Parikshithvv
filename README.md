## 🚀 Shipped Projects

### 📦 PawnSafe — Offline Pawnbroker Management System
`Kotlin` `Jetpack Compose` `Room DB` `Hilt` `CameraX` `ML Kit` `Apache POI`

A fully **offline** Android app built for a real, licensed jewellery pawnbroking business — digitizing physical pledge and redemption registers.

- 🔍 On-device **OCR pipeline** (CameraX + ML Kit) auto-extracting 14+ fields from scanned pledge tickets
- 🗃️ Clean Architecture (Data → Domain → UI) with Room DB across 3 relational tables for real-time customer lookup
- 📈 Date-indexed interest-rate engine — zero hardcoded values, accurate across rate changes over time
- 📊 Excel export module (Apache POI) generating 3-sheet reports via Storage Access Framework
- ⏰ WorkManager background worker auto-flagging overdue pledges (365-day threshold)
- ✅ Unit-tested core interest & export logic

### 🛒 ShopEase — Full-Stack E-Commerce Android App
`Kotlin` `Jetpack Compose` `Firebase` `Razorpay` `MVVM`

End-to-end shopping experience — browsing, cart, checkout, and order tracking across 10+ screens.

- 💳 Integrated **Razorpay** payment gateway for secure real-time checkout
- 🔥 Firebase Auth + Firestore sync — **30% faster** data fetch via structured queries
- 🧩 6 reusable Composables (ProductItemView, CartItemView, BannerView, etc.) — **40% less** UI dev time
- 💰 Automated tax & discount checkout across 3 pricing tiers
- 📐 Swapped manual LazyColumn chunking for LazyVerticalGrid — **25% less** layout code, consistent across 5 screen sizes

### 💰 FinanceCompanion — Personal Finance Tracker
`Kotlin` `Jetpack Compose` `Room DB` `Hilt` `DataStore`

Offline-first personal finance tracker with structured spending insights.

- 🗄️ Room DB with structured DAO queries, fully offline-first
- 💉 Hilt DI — **35% less** boilerplate across 8+ feature screens
- 📊 Dynamic insights module surfacing spending patterns & budget analytics
- 🌗 Light/dark mode with DataStore-backed preference persistence
